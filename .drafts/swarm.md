# Swarm

Swarm (рой) ИИ-агентов:

- Swarm — это несколько ИИ-агентов без «начальника»: они сами делят задачу, спорят и фиксируют решения.
- Рою нужны четыре вещи: общая цель, общая ветка, канал связи и протокол из трёх фаз.
- На большой задаче рой справился почти вдвое быстрее одиночного агента при том же качестве.
- На мелких задачах рой не нужен — он раскрывается на длинных и тяжёлых.

## Что такое swarm-режим

Swarm (в переводе с англ. — «рой») — подход в разработке с использованием ИИ, при котором несколько агентов координируют действия между собой и работают как единое целое (по аналогии с пчелиным роем). В таком режиме:

- нет главного агента;
- решения принимаются путём спора или голосования;
- по бенчмаркам Anthropic, модель взаимодействия в swarm выполняет работу на 90% качественнее одиночного агента;
- по оценкам экспертов, рой из трёх воркеров даёт прирост:
  - в 2,5 раза по качеству;
  - в 1,5 раза по скорости — на сложных задачах.

## Когда использовать swarm

Режим подходит для тяжёлых и длинных задач — он усиливает результат и ускоряет процесс. На мелких задачах преимущества не раскрываются.

## Ключевые условия для работы роя

1. **Одна общая цель** вместо разбитого плана. Задача не делится заранее — агенты получают цель целиком и делят её между собой на ходу.
2. **Одна общая ветка.** Участники работают в одном каталоге на одной ветке и видят правки друг друга в реальном времени.
3. **Канал связи.** У каждого агента есть позывной (А, Б, С). Агент может писать конкретному напарнику или всем сразу. Есть особый тип сообщения «решение» — оно становится обязательным для всей команды.
4. **Протокол из трёх фаз:**
    - **Фаза 1: координация.** Агенты читают репозиторий, формулируют, какую долю цели берут на себя, и отправляют это остальным. Конфликты решаются сразу.
    - **Фаза 2: реализация.** Каждый агент пишет только свой кусок задачи.
    - **Фаза 3: догон.** Агент обрабатывает накопившиеся сообщения после завершения текущей работы. Раундов ограничено, чтобы избежать бесконечного обмена сообщениями.
5. **Правило «отвечать только по делу»** — без лишних «принял», «согласен». Если нечего сказать по существу, агент просто продолжает работу.

## Результаты тестирования

Проведён тест с одинаковым промптом в двух режимах:

- **swarm-режим** (2 агента, Claude Opus): 11 минут 12 секунд.
- **Соло-режим** (одиночный воркер): 20 минут 22 секунды.

**Выводы по тесту:**

- swarm-режим справился почти в 2 раза быстрее.
- По качеству результат не уступает соло-режиму, а в ряде случаев может превосходить (особенно если комбинировать разные модели).
- Соло-воркер быстрее «забивает» контекст, начинает «галлюцинировать», путаться и забывать задачи.

## Дополнительные возможности

В swarm-режиме можно запускать агентов на разных моделях (например, Claude Opus + Codex Astra), что даёт уникальный подход к решению задачи за счёт разного мышления агентов.

---

**Краткий итог:** swarm-режим эффективен для масштабных задач — он ускоряет выполнение и повышает качество за счёт координации между агентами. Ключевое — соблюдать протокол и условия работы роя.
